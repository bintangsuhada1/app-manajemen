# Roadmap Pengembangan

## V1 - Fondasi Operasional
- Landing page company profile
- Login + RBAC
- Dashboard ringkasan
- Proyek, pelanggan, penawaran, invoice
- Keuangan sederhana
- Laporan harian teknisi
- Upload dokumen
- Material sederhana

## V2 - Automasi Kontraktor
- Kalkulator RAB berdasarkan template item pekerjaan
- Approval penawaran/invoice
- Export Excel lengkap
- Kalender proyek dan reminder otomatis
- SOP/checklist berdasarkan jenis pekerjaan
- Laba/rugi per proyek otomatis

## V3 - Enterprise
- Multi-cabang
- Integrasi WhatsApp notifikasi
- E-sign approval
- Audit log detail
- Mobile PWA teknisi
- Integrasi storage cloud dan backup database
